# C51 з нуля

Це короткий старт для C-режиму симулятора ADuC841. Компілятор перетворює C51 у ASM, а потім у код 8051. Для першої програми не потрібні окремі бібліотеки чи лінкер.

## Перша програма

```c
#include <stdint.h>

int main(void)
{
    uint8_t value = 0;

    while (1) {
        P0 = value;       // показати число на шині P0
        value++;          // збільшити число
        delay();          // затримка симулятора
    }

    return 0;
}
```

У редакторі C введи `starter` і натисни Tab, щоб вставити цей приклад. Працюють обидва звичайні варіанти точки входу: `int main()` і `int main(void)`. Для C51 також можна написати `void main(void)`.

## Найнеобхідніший синтаксис

```c
uint8_t led = 0;          // 8 біт, 0..255
uint16_t count = 1000;    // 16 біт
int signedValue = -2;     // знакове 16-бітне число

led = 1;                  // присвоєння
led += 2;                 // скорочене присвоєння
led++;                    // +1

if (led == 3) {
    P0 = 0xFF;
} else {
    P0 = 0x00;
}

for (uint8_t i = 0; i < 8; i++) {
    P1 = i;
}

while (P1.0) {
    P0 = 0xAA;
}
```

Підтримуються коментарі `//` і `/* ... */`, математичні та побітові оператори, `switch/case`, `break`, `continue`, функції з параметрами, масиви, вказівники, `struct`, `enum`, `typedef`, `const`, а також `true` і `false` з `<stdbool.h>`.

## Порти та біти ADuC841

```c
#include <ADUC841.H>

sbit LED = P1^0;

int main(void)
{
    set_bit(LED);
    if (read_bit(LED)) {
        clear_bit(LED);
    }
    return 0;
}
```

Доступні `P0`, `P1`, `P2`, `P3` та SFR з карти ADuC841. Команди `set_bit`, `clear_bit`, `toggle_bit`, `pulse_bit`, `read_bit`, `wait_bit_high/low`, `start_timer0/1`, `enable_uart` та інші апаратні скорочення одразу розгортаються в інструкції 8051.

## Що поки не є повною бібліотекою C

Це навчальний C51-компілятор для мікроконтролера, а не desktop C. `stdio.h`, `printf`, динамічна пам'ять і довільні зовнішні бібліотеки не підключаються автоматично. Для виводу використовуй порти, LCD, клавіатуру та інші прилади симулятора.
